# Android安装与手机接入

本文是开源版文档草稿，面向自有或已获得授权管理的手机与SIM卡。

## 安装App

使用维护者正式发布的APK。最低Android6.0/API23，低于该版本不能安装；即便版本满足，各厂商的后台运行和安装器仍可能有差异。

首次安装可用手机系统浏览器打开自己的`https://sim.example.com/a`，下载后打开APK。该页面需要管理员先在后台「系统更新 → App独立发布」上传并确认APK。网页可展示下载二维码；不需要登录管理后台即可下载。

已经安装过的手机选择覆盖安装，不要先卸载。APK包名、签名必须和已安装版本一致，versionCode必须递增。

当前历史APK使用开发阶段调试签名。社区正式发行签名方案待确认；不要把其他人自行编译的新签名APK直接用于覆盖已有设备。

## 扫码连接

1. 管理员登录自己的站点，打开「采集设备」，新增手机名称。无需先选择店铺。
2. 由后台生成接入码并展示接入二维码。二维码包含连接凭据，不能放进公开Issue、截图或README。
3. 手机App进入「设置 → 扫码接入」，扫描该二维码，核对服务器域名并保存。
4. 点击「启动采集」。系统会申请短信接收、电话/SIM等必需权限；通知、摄像头、本机号码和补充网络状态按实际用途申请。不同Android版本的权限弹窗可能分多次显示。
5. 回到Web后台，确认出现新的同步时间与运行状态。

读取本机号码是可选能力，运营商SIM未写入号码、系统权限或ROM限制都可能导致读取不到。读取失败时手动录入并绑定号码，无需向本机发送验证短信。

## 日常三个页签

- **运行**：查看采集状态、连接、SIM和待上传数量，进行同步。
- **检查**：集中查看权限、系统电池限制和厂商后台运行设置。
- **设置**：扫码连接、检查更新和诊断。

使用专用采集手机能减少无关短信进入设备和后台的机会。不要把未取得授权的手机、号码或短信接入本站。

## 插卡、换卡与绑定

后台以手机号管理手机卡，App提供SIM订阅信息来判断收到短信的具体卡。日常操作不要求用户猜测订阅编号。

识别到号码后仅在号码唯一匹配、状态和权限满足条件时自动关联；无法确认时手动选择。新插卡、换卡后等待上报并核对手机号。不能把“检测到一张SIM”直接当作“号码已识别且归属正确”。

换绑影响后续消息归属；已经收到的消息保留当时的绑定版本，避免旧队列被重新归到新号码或其他人的店铺。

## 后台持续运行

按手机实际系统名称设置：

- 系统电池优化：对App选择“不优化/不限制”。
- 厂商后台管理：允许自启动、后台活动；vivo常见选项是允许“后台高耗电”。
- 最近任务有锁定功能时可锁定App，减少清理误停。
- 持续通知便于查看运行状态；系统杀进程、断网、无信号都可能导致延迟。

这些选项不能保证所有机型永久运行。上线前分别验证锁屏、断网恢复、重启和双卡各自的消息归属。

## 更新失败时

当前部分旧版及厂商在线安装器已有失败反馈。浏览器打开本站`/a`，下载后从文件管理器覆盖安装，是备用路径。若修复存在于新版App，旧App只有成功覆盖安装后才会执行新版更新逻辑。

不要通过卸载解决覆盖升级问题，以免删除连接配置和本机待上传短信。反馈时提供App版本、手机型号、Android版本、安装来源和错误截图，隐藏真实验证码与接入码。
