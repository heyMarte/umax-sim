# 平台与店铺标签

号码是主要管理对象。平台、店铺均可不填；同一个号码可关联不同平台上不同名称的店铺，并分别分配运营权限。

在私有`server/config/config.php`追加：

```php
'platform_catalog' => [
    'amazon' => ['label' => 'Amazon', 'keywords' => ['amazon']],
    'internal' => ['label' => '内部用途', 'keywords' => []],
],
```

重新登录后前端会读取站点目录。既有三家默认平台保留，配置可以修改其显示名称或追加标签。最多16项（包含默认三家）；标识1至16位、小写字母开头，后面允许字母数字、下划线、短横线；all/unknown保留给筛选器。

label为纯文本，最多80个字符。keywords为最多8个非空字符串，每个最多64个字符，用于按发件人/正文中的明确关键词判断来源。空列表不做来源推断。多个平台同时匹配时保持待确认；标签名本身不会被当成来源关键词。不要配置易混淆的短词来扩大匹配。

标识是保存到历史数据中的身份，请保持稳定；删除自定义配置不会把历史消息重算成别的平台，但该平台将不能用于新的录入和筛选配置。建议长期保留旧标识并修改显示名称。已有消息的号码和权限归属不会因目录调整而重新分配。

平台标签只帮助识别号码用途与短信来源，不代表已经对接该平台的商品、订单或官方API。
