# 0.6.3 微信密钥授权和关注指引

本次只更新 PHP 后台，Android App 无需更新。

## 管理员配置

在「微信推送 → 公众号配置」填写公众号名称，上传该公众号官方提供的关注二维码（PNG、JPG 或 WebP，最大512KB），再保存。这里上传的是公众号关注码，个人微信绑定码仍由系统为当前登录账户单独生成。

接收人进入「微信推送 → 我的微信接收」即可看到公众号名称、关注二维码，以及后续绑定入口。在手机微信中打开授权后的提示页，也会看到同一公众号的关注指引。本站不自动生成公众号官方关注码；应由公众号管理者提供。

公众号资料修改不影响现有微信绑定、已测试状态或自动推送。更换 AppID 时旧公众号的绑定会失效，未明确更新的旧关注二维码会清除，避免接收人关注错误公众号。

## 权限分别分配

在「账户管理 → 店铺与权限 → 微信推送」设置：

- 配置公众号资料和微信推送通道：可修改名称、关注二维码、AppID、模板和本站地址，以及控制推送开关。
- 设置和更换公众号密钥：可设置 AppSecret；未授予时隐藏密钥区域，服务端也拒绝越权修改。已保存的密钥对所有人均不回显。
- 接收本人授权范围验证码：用于个人绑定和收码；还需短信查看、复制权限。

超级管理员自动拥有全部权限。原先仅有通道配置权限的普通账号不会自动获得新的密钥权限，需要管理员单独授予。普通接收人仍可查看关注信息并绑定微信。

修改推送通道或密钥后自动暂停推送，需要重新测试当前配置后开启；仅修改公众号名称和关注二维码不会暂停推送。

## 升级

在现有后台「系统更新」上传 `umax-sim-online-release-0.6.3.zip`，升级完成后刷新网页。新增公众号资料字段会自动迁移；现有公众号密钥保留。无需覆盖数据库配置、密钥保管文件或运行数据。手动部署见 [安装文档](INSTALL.md)。
