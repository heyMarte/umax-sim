# 0.7.0 Outlook 邮箱收码

本次新增个人 Outlook／Hotmail 邮箱接入、批量导入、微软授权、自动收取验证码和运营分配。Android App 不变。

在现有后台“系统更新”上传 `umax-sim-online-release-0.7.0.zip`，升级后刷新网页。新增邮箱数据表自动迁移，现有短信、号码、微信配置保留。

升级后先按 [Outlook配置与部署](OUTLOOK.md) 注册并配置一套支持个人账号的微软应用，再逐个授权自己的邮箱，启动 `bin/mail-worker.php --loop`。授权在服务器续期，运营在自己的电脑登录系统即可查看获授权邮箱。

安装更新包不会自动获取任何真实邮箱的授权。真实收件需要完成上述应用配置和邮箱授权；原有短信收码继续按原流程使用。
