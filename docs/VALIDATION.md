## 本地复查

```bash
bash scripts/check.sh
python3 scripts/package.py
```

完整数据库测试需要单独的临时数据库和私有配置，不在上述无数据库检查中自动执行。`server/tests/db_checks.php`要求库名以_test结尾；其他破坏性测试也不能对生产库运行。

HTTP烟雾验证要求已启动、使用测试数据的本机服务，且测试配置包含PLATFORMS.md中的amazon目录项、微信保持全新未配置状态：

```bash
export SIM_SMOKE_USER='你的测试管理员'
# 通过安全的本机方式设置SIM_SMOKE_PASSWORD，不提交到文件或命令历史
python3 scripts/integration-smoke.py --base-url http://127.0.0.1:18760
```

脚本只允许localhost，使用HTTP开发服务时测试配置的secure_cookie需为false；正式部署必须恢复true并使用HTTPS。HTTPS本地服务可通过--ca传入信任的本地测试证书；脚本不会关闭TLS证书验证。
