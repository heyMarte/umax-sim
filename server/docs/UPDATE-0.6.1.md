# 0.6.1 店铺名称限制修复

本版仅更新后台，Android App不用更新。

## 修复

- 店铺名称作为显示标签，不再要求同一平台内唯一；同名店铺各自保留独立编号和权限。
- 回收站内的名称不占用新店铺名称；恢复时也不因重名失败。
- 改名继续关联原号码，不合并店铺、不改变历史短信归属。
- 关联选择、授权选择出现同名店铺时，补充关联手机号和店铺编号，便于区分。
- 编辑店铺的提示简化；店铺保存冲突不再混报号码、账户或密钥问题。

## 升级

在已有后台「系统更新」上传 `umax-sim-online-release-0.6.1.zip`，校验后升级后台。升级器先备份，再执行迁移；完成后刷新网页。不要选择源码ZIP，也不用重新发布App。

可从0.4.3及以上版本使用专用在线包升级，包括原个人部署版本。原config.php、keyring.php、已发布App及运行数据继续保留。原微信配置不会被默认空配置覆盖。

手动覆盖备用：先备份，将更新包中的src、public、bin、docs等程序文件覆盖到现有项目根目录，保留私有配置和var；在原项目目录执行（宝塔PHP8.2示例）：

```bash
/www/server/php/82/bin/php bin/console.php migrate
/www/server/php/82/bin/php bin/console.php health
```

迁移会移除店铺名称唯一索引并保留普通查询索引，不删除任何店铺或修改其编号。更新结果应显示0.6.1 healthy。无需重建数据库、重新绑定手机或恢复已删除的店铺。

## 验证范围

真实MariaDB回归覆盖：历史分组店铺改为同名、同平台重复名称创建、回收站名称复用/恢复、ID关联和历史消息不变、同名不扩大授权范围、重复迁移。前端覆盖同名选择项区分。另以实际页面验证保存成功后关闭弹窗。
