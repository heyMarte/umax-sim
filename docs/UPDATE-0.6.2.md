# 0.6.2 管理员数据管理更新

本次仅升级 PHP 后台，Android App 保持 0.6.0，无需重新安装。

## 管理员可直接操作

- 修改已关联号码的店名和平台标记，名称可重复，可选择多个或不选平台。
- 同一个号码可关联同平台的多家店铺；编辑时保留现有多家关联，也可继续添加。
- 将店铺转移到已有同平台店铺的号码。
- 删除仍关联号码或历史记录的店铺，系统自动解除当前号码关联，保留手机卡、短信及资金流水。
- 永久删除回收站中的店铺、设备、号码、账户及历史记录；关联和绑定由系统处理。
- 号码有流水时仍可修改国家；旧流水保留原币种，当前余额仅采用当前币种的记录。
- 恢复原号码已永久删除的历史流水。
- 编辑、禁用、删除管理员账户，包括当前登录账户和最后一个管理员。操作后相应会话退出；需要重建管理员时可在服务器运行 `bin/create-admin.sh`。

普通账户继续按已分配的功能、店铺范围和现有规则操作。管理员的身份验证、数据格式与并发写入校验正常执行。

同平台的多个店铺共用一个号码时，短信无法唯一确定属于哪家店铺的，保留为未归属短信，由管理员查看；系统不会随机选店铺分发验证码。

## 升级现有站点

1. 下载 `umax-sim-online-release-0.6.2.zip`。
2. 在后台「系统更新」上传 ZIP 并升级后台。
3. 升级器先备份，再迁移和检查运行状态；完成后刷新网页。

也可按 [安装文档](INSTALL.md) 中的手动升级步骤覆盖程序文件并执行迁移。不要覆盖现有 `config/config.php`、`config/keyring.php` 或运行数据目录。

升级只开放操作能力，不会自动删除任何现有业务数据。删除店铺不会连带删除手机卡和历史记录；永久清空回收站只处理已在回收站的项目。
